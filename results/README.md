# Experiment results

**No LLM results are included yet.** This is intentional. The dataset and Python unit tests are not evidence of model behaviour.

After you run a real model, manually review `outputs/model_responses.csv` and `outputs/model_report.md`, then copy a reviewed version into this folder (removing any private information). Add model name, version, date, test condition, run settings and study limitations to the report. `outputs/` is excluded from version control by default.
